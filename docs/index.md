# WitnessProtectionProgram

WPP protects Midnight private application data through local encryption and
recoverable backups. Google Drive is the first beta storage destination. Working
developer components include package encryption, recovery packs, a local
ciphertext journal, encrypted catalog modules, and a live synthetic Drive round
trip. The complete consumer application is still in development.

Start with [Understanding WPP](explanation/application.md) for the problem, intended
user experience, storage design, and current limits. This site separates runnable
developer guides from planned application behavior.

The documentation follows [Diátaxis](https://www.diataxis.fr/) and is built with
[Sphinx](https://www.sphinx-doc.org/en/master/).
