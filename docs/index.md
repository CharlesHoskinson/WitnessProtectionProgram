# WitnessProtectionProgram

WPP is a proposed local encryption and recovery layer for Midnight private state.
Google Drive is the first planned beta storage provider. The application is not
implemented yet; this site distinguishes design requirements from working tools.

The documentation follows [Diátaxis](https://www.diataxis.fr/) and is built with
[Sphinx](https://www.sphinx-doc.org/en/master/).
