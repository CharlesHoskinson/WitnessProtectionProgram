The Google Picker is a "File Open" dialog for information stored on
Google Drive. For more information, see [Overview of the
Google Picker](https://developers.google.com/workspace/drive/picker/guides/overview).

You can use the [Google Picker API for web
apps](https://developers.google.com/workspace/drive/picker/guides/web-picker) or the [Google Picker API for
desktop and mobile apps](https://developers.google.com/workspace/drive/picker/guides/desktop-mobile-picker)
to allow users to open or upload Drive files. The Google Picker API
is separate from the Google Drive API.

To allow users to open Drive files from a mobile app, refer to
[Use the Google Picker with Android
apps](https://developers.google.com/workspace/drive/picker/guides/desktop-mobile-picker#mobile-picker).

To view a full code sample for web apps, see [Use Google Picker API features in web
apps](https://developers.google.com/workspace/drive/picker/guides/web-picker-sample).
